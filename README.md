# AssetStudioWeb 

AssetStudioWeb is a variant of AssetStudio written in TypeScript.

Live demo in https://cobbfan9.github.io/asset-extractor-web/

It is still in early phases and does not have a stable api, it also only works in the browser.

See tools/test-site to get a bit of an idea how it works. Once stable I can add full documentation.
